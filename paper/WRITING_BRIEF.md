## 3. 占位约定（**不要留空、不要猜**）

正文里任何"现在还不能确定的量"一律写成：

```
【待补·<ID>】<一句话说明>（来源：<哪批实验 / 哪个文件 / 哪个脚本>；<当前状态>）
```

例：`【待补·P03】达标吞吐的三点并排（来源：`S14H` 的 min512/256/128；待 D1② 跑完）`

* ID 用小写字母+数字（`P01`…），**全局唯一**；补数时把它连同那一行替换成真内容。
* **禁止**用 `TBD` / `XXX` / 空白 / 0 —— 0 是测量值，缺失是缺失，两者语义相反（`README.md` §8）。
* 清点：`python scripts/list_paper_placeholders.py`（分组列出、给出总数、**有待补则非零退出**）。
